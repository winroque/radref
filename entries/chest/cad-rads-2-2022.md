# CAD-RADS 2.0 (2022)

> Per-patient category from the **most severe** stenosis in vessels > 1.5 mm: 0 (no plaque),
> 1 (1–24%), 2 (25–49%), 3 (50–69%), 4A (70–99%), 4B (left main ≥ 50% or three-vessel ≥ 70%),
> 5 (100%), N (non-diagnostic). Add plaque burden P1–P4 and modifiers in the order
> N, HRP, I, S, G, E, separated by "/". [cad-rads-2-2022]

## 1. Scope

- **Applies to:** coronary CT angiography in stable or acute chest pain.
- **Does not cover:** non-coronary findings (report separately).

## 2. Definitions

| Term | Definition | Source |
|---|---|---|
| Stenosis grading | 0% none; 1–24% minimal; 25–49% mild; 50–69% moderate; 70–99% severe; 100% occluded | [cad-rads-2-2022, Table 1] |
| Plaque burden | P1 mild, P2 moderate, P3 severe, P4 extensive; by CAC 1–100 / 101–300 / 301–999 / > 1000, or segment involvement score ≤ 2 / 3–4 / 5–7 / ≥ 8, or visual by vessel; P0 not used | [cad-rads-2-2022, Tables 1–2] |
| HRP | ≥ 2 of: positive remodeling (remodeling index > 1.1), low-attenuation plaque (< 30 HU), spotty calcification, napkin-ring sign | [cad-rads-2-2022] |
| Modifier I | CT-FFR or CT perfusion done: I+ positive, I− negative, I+/− borderline | [cad-rads-2-2022, Table 1] |
| CT-FFR thresholds | I+ ≤ 0.75 (lesion-specific, in a vessel suitable for PCI); I± 0.76–0.80; I− > 0.80; measure 1–2 cm distal to the stenosis; delta > 0.12 significant; use in 50–90% stenoses, and in CAD-RADS 2 only for a proximal lesion ≥ 40% | [cad-rads-2-2022, Table 6] |
| CT perfusion | Fixed infarct = I−; peri-infarct ischaemia = I+ | [cad-rads-2-2022, Table 7] |
| Modifier E | Non-atherosclerotic abnormality (dissection, anomalous origin, aneurysm, vasculitis, fistula, extrinsic compression…) | [cad-rads-2-2022, Table 3] |

## 3. Criteria / categories

| Category | Stenosis | Stable chest pain — further testing | Acute chest pain — interpretation | Source |
|---|---|---|---|---|
| 0 | No plaque or stenosis | None | ACS highly unlikely | [cad-rads-2-2022, Tables 4–5] |
| 1 | 1–24% (or plaque with positive remodeling and no stenosis) | None | ACS unlikely | [cad-rads-2-2022, Tables 4–5] |
| 2 | 25–49% | None | ACS less likely | [cad-rads-2-2022, Tables 4–5] |
| 3 | 50–69% | Consider functional assessment | ACS possible | [cad-rads-2-2022, Tables 4–5] |
| 4A | 70–99% in one or two vessels | Consider ICA or functional assessment (ICA favoured if > 90%, HRP or I+) | ACS likely | [cad-rads-2-2022, Tables 4–5] |
| 4B | Left main ≥ 50% or three-vessel ≥ 70% | ICA recommended | ACS likely | [cad-rads-2-2022, Tables 4–5] |
| 5 | Total (or subtotal) occlusion | Consider ICA, functional and/or viability assessment | ACS very likely | [cad-rads-2-2022, Tables 4–5] |
| N | Non-diagnostic study | Additional or alternative evaluation | ACS cannot be excluded | [cad-rads-2-2022, Tables 4–5] |

- N as a **category** replaces the number when no diagnostic segment shows ≥ 50% stenosis; N as a
  **modifier** follows a diagnostic stenosis ≥ 50% (e.g. `CAD-RADS 3/P2/N`). [cad-rads-2-2022]
- In-stent stenosis is graded like native vessels (e.g. `CAD-RADS 4A/P3/S`); a non-evaluable stent
  with no other stenosis → `CAD-RADS N/P2/S`. With bypass grafts, grade grafts and native segments
  from the anastomosis distally only. [cad-rads-2-2022]

## 4. Management

- Management depends on the category plus P (P3–P4 → aggressive preventive therapy in any
  category) and modifiers (I+ or HRP favour ICA or admission in some settings). HRP calls for more aggressive
  management even in CAD-RADS 1–2; in acute chest pain consider admission/observation even
  without severe stenosis. The source's
  Tables 4–5 give the full wording; summarized above. [cad-rads-2-2022]

## 5. Pitfalls

- Using one HRP feature to apply the modifier (two are required).
- Grading vessels < 1.5 mm (the tables apply to vessels > 1.5 mm).
- Using CAC alone for plaque burden: it needs at least a qualitative assessment of non-calcified
  plaque. [cad-rads-2-2022, §3.2.1]
- Ordering modifiers incorrectly (N, HRP, I, S, G, E).

## 6. What the source does not say

- No single preferred method for plaque burden. If methods disagree, the Table 2 note says to
  use CAC or total plaque quantification if available, while the text (§3.2.1) says the most
  severe assessment applies when several methods are used.

## 7. Disagreements and newer versions

- Replaces CAD-RADS 2016: adds P1–P4, I and E; "vulnerable plaque (V)" renamed HRP. [cad-rads-2-2022]
- Internal inconsistency: the Fig. 13 legend calls P3 "extensive" plaque burden, while Table 1
  defines P3 as severe and P4 as extensive.
- Internal inconsistency: Fig. 17 codes "CAD RADS 3/P3/S/HRP", contrary to the stated modifier
  order N, HRP, I, S, G, E (§3.4; Table 8).
